# Auvellion Updates

Öffentliche Auslieferung der Auvellion-Programme: fertige Programmversionen und unterschriebene Lizenz-Statuslisten.

**Hier liegt nichts Vertrauliches:** kein Quelltext, keine Kundendaten, keine Schlüssel. Alle Dateien werden von der
Auvellion-Firmen-App erzeugt und digital unterschrieben (Ed25519). Die Programme prüfen jede Datei mit dem eingebauten
öffentlichen Schlüssel; veränderte oder fremde Dateien werden abgelehnt.

| Ordner | Programm | Dateien |
|---|---|---|
| `capellia/` | Capellia · Salon Management | `lizenzen.json` (Statusliste), `version.json` (neueste Version) |
| `velor/` | VELOR für Autohäuser | später |

Die Programmdateien selbst (z. B. `Capellia-v0.4.0.zip`) liegen unter **Releases** dieses Projekts.

Beschreibung der Schnittstelle: „Lizenz- und Update-Schnittstelle (Auvellion-Firmen-App ↔ Programme)“, Format 1.
